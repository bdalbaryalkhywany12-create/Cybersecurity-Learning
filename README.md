# بصمة الخيواني

متجر إلكتروني تجريبي باللغة العربية، مبني باستخدام HTML وCSS فقط.

## الملفات
- `index.html` — هيكل صفحات ومحتوى الموقع.
- `style.css` — الألوان والتنسيقات والتصميم المتجاوب.

## التشغيل
افتح ملف `index.html` في متصفح الإنترنت.

## ملاحظة
المنتجات والأسعار وبيانات التواصل أمثلة قابلة للتعديل. نموذج التواصل واجهة شكلية ولا يرسل البيانات فعلياً دون ربطه بخدمة خلفية.
